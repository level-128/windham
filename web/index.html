About Windham Web

Windham Web is an in-browser encrypted disk unlocker. Upload a FAT32 or exFAT disk image created by Windham, enter your passphrase, and browse, navigate, and download files — all decryption happens locally in WebAssembly. No data leaves your machine.

Creating a disk on any ISO C platform: GNU/Linux, macOS, BSD, Zephyr, HarmonyOS, QNX, Windows, WASI and Nuttx. 

windham New disk.img --diskfile="your size here" --create-exfat

Creating a FAT32 or ExFAT disk manually on GNU/Linux or Linux-kernel based OS with GNU compatible libc (musl …)

windham New disk.img --diskfile="your size here"
sudo windham Open disk.img --to="Optional name"
# FAT32
sudo mkfs.vfat -F 32 -n "your volume name" /dev/mapper/your_name
# exFAT
sudo mkfs.exfat -n "your volume name" /dev/mapper/your_name
sudo windham Close your_name

Note: it is possible to pass /dev/sdx or /dev/nvme0nxpx as disk image. This is not recommended. No test has been made to cover all browser combos for such use case.
